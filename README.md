# AI English Learning Data Collector

A web-based data collection tool for the research project:

**AI-Assisted English Learning and Critical Evaluation of AI-Generated Information: A Task-Based Study of University Students’ Use of Generative AI in Language Learning**

## Purpose

This tool is used to collect student submissions and records related to AI-assisted English learning activities.

The collected data may include:

- Project code
- Project number
- AI tool
- AI model/version
- Date and time
- Student prompts/instructions
- AI-generated outputs
- Fact-checking records
- Sources used for verification
- Accuracy judgments
- Student revisions/modifications
- Final student-produced work
- Student reflections/evaluations

## Technology

- HTML
- CSS
- JavaScript
- GitHub Pages
- Google Apps Script
- Google Sheets

## Data Collection

The website provides the student-facing interface. Submitted data are processed through Google Apps Script and stored in a controlled Google Sheets environment.

No research data are stored directly in this GitHub repository.

## Deployment

The website is hosted using GitHub Pages.

Student-facing website:

https://n-sanitdee.github.io/ai-english-data-collector/

## Project Status

Currently under development.

## Research

This tool supports data collection for research on university students' interaction with generative AI in English-language learning, including their identification, verification, and revision of AI-generated information.
